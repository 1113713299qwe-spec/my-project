# 致敬张雪峰老师 · 五分钟纪念短片

一个无需安装依赖、可直接在现代浏览器中播放和导出的 5 分钟（05:00）原创纪念视频。作品采用程序化绘制的书页、讲台、星光、道路等视觉意象，不使用或仿制人物肖像，也不虚构具体生平事实。

## 使用方式

```bash
python -m http.server 8000
```

浏览器打开 <http://localhost:8000>。支持播放、暂停、拖动进度、章节跳转、静音、全屏和键盘控制（空格、左右方向键）。

点击“导出 WebM 视频”后，页面会按实际时长实时录制 5 分钟，自动下载带原创氛围音轨的 1080p WebM 文件。推荐最新版 Chrome 或 Edge；导出期间请保持页面在前台。

## 影片结构

1. 序章：因为有人愿意把话讲明白（00:00–00:25）
2. 看见：在选择的路口看见每一份迷茫（00:25–01:05）
3. 说清：把复杂的世界讲成听得懂的话（01:05–01:45）
4. 真诚：一份坦率胜过无数漂亮答案（01:45–02:25）
5. 选择：答案从来不是唯一（02:25–03:05）
6. 陪伴：屏幕这一端的声音陪很多人走过长夜（03:05–03:45）
7. 回响：一堂课会结束，影响却仍在继续（03:45–04:25）
8. 尾声：谢谢您，张雪峰老师（04:25–05:00）
