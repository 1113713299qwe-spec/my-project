# AI Relationship Reply Assistant

一个本地运行的 AI 恋爱聊天回复助手 Web App。用户可以输入文字聊天记录、上传聊天截图，AI 会结合恋爱课程知识库、思维导图和聊天原则，分析对方状态、指出聊天问题，并生成自然、尊重、有边界感、可直接发送的回复。

> 安全边界：本项目不用于操控、欺骗、胁迫、骚扰、PUA 或诱导亲密关系。所有 AI 输出都应基于尊重、同意、真实表达、边界感和健康关系沟通。

## 功能列表

- 首页产品介绍与快捷入口
- 聊天分析：支持文字、图片截图、文字 + 图片混合输入
- 图片预览、删除、base64 data URL 上传
- 当前关系阶段、用户目标、回复风格、知识库影响强度配置
- 结构化 AI 分析结果卡片：状态、评分、问题、策略、回复、错误示例、下一步、知识库引用
- 回复复制与收藏
- 知识库 / 思维导图管理：新增、编辑、删除、启用、禁用、权重、标签、搜索、上传 `.md` / `.txt` / `.json`
- 案例复盘：保存分析结果、编辑采用回复与后续备注、删除案例
- 设置页：模型名、默认风格、默认知识库强度、安全提醒、默认保存、API Key 配置状态
- 预留扩展：xmind、PDF、OpenAI File Search / vector store、登录、云同步、PWA、不同聊天场景模板、对象档案、OCR 纠错、回复效果评分

## 技术栈

- Next.js + React + TypeScript
- Tailwind CSS
- Next.js API Route
- OpenAI 官方 npm 包与 Responses API
- localStorage 本地数据存储

## 安装方法

```bash
npm install
```

## 配置 OPENAI_API_KEY

复制示例环境变量文件：

```bash
cp .env.example .env.local
```

编辑 `.env.local`：

```bash
OPENAI_API_KEY=sk-your-openai-api-key
```

设置页只会显示是否已配置，不会展示完整 Key。

## 启动命令

```bash
npm run dev
```

浏览器打开：<http://localhost:3000>

## 如何输入文字聊天记录

1. 进入 `/analyze`。
2. 在“文字聊天记录”中粘贴聊天内容，例如：
   ```text
   我：今天干嘛呢？
   她：没干嘛，躺着。
   我：那我陪你聊会？
   她：哈哈不用。
   ```
3. 选择关系阶段、目标、回复风格和知识库影响强度。
4. 点击“AI 分析”。

## 如何上传聊天截图

1. 进入 `/analyze`。
2. 在“上传聊天截图”中选择一张或多张 `png`、`jpg/jpeg`、`webp` 图片。
3. 前端会显示缩略图，可删除不需要的图片。
4. 点击“AI 分析”后，后端会将图片 data URL 作为 `input_image` 传给 OpenAI Responses API，让模型先识别截图内容再分析。

## 如何添加思维导图

1. 进入 `/knowledge`。
2. 类型选择“思维导图”。
3. 可以直接粘贴思维导图文本，也可以上传 `.md`、`.txt`、`.json` 文件。
4. 设置标签、权重、启用状态后点击保存。
5. 第一版已预留 `.xmind` 和 PDF 解析入口，上传时会提示后续扩展。

## 思维导图如何影响回复

`src/lib/knowledge.ts` 中的知识库上下文构建器会读取启用的知识库内容，根据当前选择的知识库模块标签、权重和影响强度筛选内容，然后把整理后的上下文加入 OpenAI system prompt：

- 低：只参考知识库大方向，回复更自然。
- 中：明显参考知识库原则，同时允许灵活发挥。
- 高：严格遵守知识库和思维导图逻辑输出。

## 如何保存案例

1. 在 `/analyze` 完成一次 AI 分析。
2. 在分析结果顶部点击“保存到案例”。
3. 进入 `/cases` 查看历史案例。
4. 可以补充“最终采用的回复”和“后续结果备注”，也可以删除案例。

## 本地数据说明

- 知识库、案例、设置均保存在浏览器 localStorage。
- 默认知识库文件位于 `src/data/relationship_knowledge.md`。
- 第一版不需要登录、不需要云数据库。
